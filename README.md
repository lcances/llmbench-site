# llmbench — articles & site

Canonical home of the **llmbench** blog: performance benchmarks of small and
medium open-source LLMs on consumer hardware — prefill/decode curves,
time-to-first-token, max context, VRAM and power, across runtimes
(llama.cpp, Ollama, vLLM) pushed to their tuning limits.

How content gets here:

- Articles and their charts land as **pull requests**, generated by a
  private benchmarking pipeline. Every number and every figure is computed
  from measured results — nothing is hand-typed.
- **Merging a PR is the publish action**: GitHub Actions renders the Quarto
  site to GitHub Pages and pushes the post to dev.to (with the canonical
  URL pointing back here).
